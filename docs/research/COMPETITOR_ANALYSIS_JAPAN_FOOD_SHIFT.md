## 1. 飲食業界におけるシフト管理市場の全体像・構造

### 1.1 飲食店の管理手法別シェア構成比（最新調査データ合算）

日本の飲食店（約60万事業所）におけるシフト管理手法のシェア構造は以下の通りです：

*   **アナログ・準アナログ（紙・Excel）が全体の約 70%〜75% を依然として占有**
    *   **紙・ホワイトボード・手書き手帳**: **約 35%〜40%**（個人店・スタッフ1〜5名の小規模店で圧倒的）
    *   **Excel / Google スプレッドシート**: **約 35%〜40%**（中規模店・店長の自作マクロ・関数）
*   **専用SaaS・クラウドシフト管理アプリ**: **約 25%〜30%**（チェーン店・大型店・FC展開企業）
*   **汎用チャットツール（LINE / LINEグループ）**: **85%〜90% 以上で併用**（実質的な業界標準インフラ）
    *   ※LINEで希望を集め、店長がそれを**紙やExcelに手打ち転記してパズルを解いている**のが典型的な現場実態。

---

### 1.2 店長が直面する「4大ペイン」とコスト換算

1.  **月間所要時間**: 1店舗（スタッフ15〜30名）あたり **月間 15〜25時間**
    *   時給換算（時給1,500〜2,000円）で **月額 30,000円〜50,000円 / 年間36万円〜60万円** の店長人件費ロス。
2.  **多次元の複雑制約**:
    *   **需要の波**: ランチピーク（11:30-13:30）、アイドルタイム（14:30-17:00）、ディナーピーク（18:30-21:00）。
    *   **スキル・ポジション**: ホール、キッチン（温場・冷場・仕込み・洗い場）、店長代行（締め・レジ金管理）。
    *   **スタッフ属性別の壁**:
        *   **学生**: 試験休み（1月・7月）、終電制限、親の扶養控除（103万円の壁）。
        *   **主婦（夫）**: 平日昼（10:00-14:00/15:00）限定、夏休み・冬休みの出勤激減、社会保険加入（106万円の壁）。
        *   **フリーター**: ロングシフト希望、週20h以上で社保加入ライン、深夜割増重視。
    *   **労働基準法**: 満18歳未満深夜業（22:00-05:00）禁止（第60条）、連続勤務上限、休憩時間付与（6h超45分、8h超60分）、週40h上限。
3.  **回収・催促の精神的ストレス**: LINE未読・提出遅れ、希望を削る「シフトカット」の申し訳なさ、急な欠勤の当日穴埋め。
4.  **人件費予算（人時売上高）のオーバー**: 閑散日の過剰配置、繁忙日の人手不足による機会損失。

### ① Airシフト（AirShift）/ シフトボード
* **運営会社**: 株式会社リクルート（Airビジネスツールズ）
* **発売時期**: 2018年4月（スタッフ向け「シフトボード」は2014年〜）
* **導入実績**: 非公開（「シフトボード」は累計数百万DL、Airレジ導入10万店舗以上の飲食基盤と接続）
* **ターゲット規模**: 個人店、1〜10店舗程度の中小飲食店
* **月額料金体系**:
  * 初期費用: **0円**
  * 月額料金: スタッフ3名以上の場合 **1人あたり330円（税込）** / 2名以下は一律 **990円（税込）**
  * 無料トライアル: **最大2ヶ月間無料**
* **スタッフ側UI/UX**:
  * 専用アプリ「**シフトボード**」（iOS/Android）を使用。若者・学生の間で圧倒的な知名度。
  * カレンダー画面からタップで希望提出、確定シフトが私生活のカレンダーに自動同期。
* **店長・管理者側機能**:
  * **シフト自動作成**: **AI・機械学習型（特許出願中）**。「シフト作成アシスト」機能により、店長が修正した配置パターンやスタッフの組み合わせのクセをAIが学習し、次回以降の提案精度を向上させる。
  * **人件費予算管理**: シフト作成画面上で概算人件費をリアルタイム算出。Airメイト・Airレジと連携し、日別売上実績・予測と突合して人件費率（FL比率）を可視化。
  * **ポジション/スキル管理**: ホール/キッチン、時間帯別必要人数、スタッフごとのスキルラベル設定。
  * **労基法違反アラート**: 週40時間超過、連勤日数、休憩時間不足などのチェック機能。
* **強み（Pros）**: スタッフのアプリ導入ハードルが低い。Airレジ・Airペイとの親和性が高い。
* **弱み・現場の不満（Cons）**: LINEではなくアプリインストールが必須。退職スタッフの連携解除忘れによる従量課金。

### ② らくしふ
* **運営会社**: 株式会社クロスビット（2023年よりSmartHRグループ）
* **発売時期**: 2018年リリース
* **導入実績**: **累計25,000事業所以上**（すかいらーくホールディングス、チムニー、DDグループ等）、**利用継続率99.4%**。
* **ターゲット規模**: 1店舗の単独店から、1,000店舗超の超大手飲食チェーンまでフルカバー
* **月額料金体系**:
  * 初期費用: 約10,000円〜（導入支援内容・規模により個別見積）
  * 月額料金: **1ユーザーあたり約360円（税抜）〜**（20名以下向け定額プランや規模別パックあり）
* **スタッフ側UI/UX**:
  * **専用アプリ不要・LINE完結**: 店舗公式LINEのリッチメニューから「希望提出」「確定シフト閲覧」「欠員募集への応募」が可能。
  * アプリインストールの拒否やログインID/パスワード紛失トラブルがゼロ。
* **店長・管理者側機能**:
  * **シフト自動作成**: **AI ＆ 数理最適化エンジン**を搭載。モデルシフト（時間帯・曜日ごとの必要人数・スキル構成）に基づき、スタッフ希望と労働法規をマッチングして最適シフトを自動生成。
  * **人件費予算管理**: 人件費予算、人時売上高、概算人件費のリアルタイムシミュレーション。
  * **ポジション/スキル管理**: ホール・キッチン、リーダー、焼き場、レジなどのスキルマトリクス管理。
  * **労基法違反アラート**: 36協定（月45時間・年360時間）、週40時間、インターバル規制、**年少者（18歳未満）の深夜22時以降制限**などの厳密アラート。
* **店舗間ヘルプ・多店舗管理**: 他店舗の不足シフトをLINEを通じて自社他店スタッフにヘルプ募集。全店シフト充足率ダッシュボード。
* **強み（Pros）**: LINE連動による「提出回収率100%・催促ゼロ」の圧倒的UX。
* **弱み・現場の不満（Cons）**: 個人店・小規模店には見積もりベースの価格が高価。

### ③ シェアフルシフト（旧 Sync Up）
* **運営会社**: シェアフル株式会社 / パーソルイノベーション株式会社（パーソルグループ）
* **発売時期**: 2018年提供開始
* **導入実績**: **累計850社以上・数千店舗**（飲食チェーン、カフェ、居酒屋、カラオケチェーンなど）。
* **ターゲット規模**: 5店舗〜50店舗以上を展開する中堅〜大手飲食チェーン（ドミナント出店企業に最適）
* **料金体系**: ストア契約、エリア契約、カンパニー契約等の個別見積制（月額固定パックまたはユーザー従量）。
* **スタッフ側UI/UX**: 専用アプリ。自店舗のシフト提出に加え「他店舗のヘルプ募集一覧」に応募可能。メダル付与機能。
* **店長・管理者側機能**:
  * **シフト自動作成**: パターン展開 ＆ ルールベース割当。
  * **店舗間ヘルプ（★最大の特徴）**: 自店で埋まらないシフト枠を近隣店舗のスタッフへヘルプ募集配信。
  * **スキマバイト「シェアフル」連携**: 埋まらなかったシフト枠をパーソルのギグワークアプリ「シェアフル」へワンクリックで外部求人出稿可能。
* **強み（Pros）**: 自社店舗間ヘルプと外部スキマバイト募集がシームレスに結合したシフト充足エコシステム。
* **弱み（Cons）**: 単独店舗ではヘルプ機能の恩恵が薄い。

### ④ Optamo（オプタモ）
* **運営会社**: 株式会社ラック（LAC） / 株式会社モーション
* **発売時期**: 2019年提供開始
* **導入実績**: イオンネクスト、大手外食チェーン、コールセンター、介護施設、物流拠点など。
* **ターゲット規模**: 中規模〜大規模飲食チェーン、調理・仕込み・配膳・清掃など時間帯別タスクが細分化された店舗
* **料金体系**: 個別見積制（スタッフ数・拠点数従量）
* **店長・管理者側機能**:
  * **数理最適化アルゴリズム（数理計画法）**:
    * `Optamo for Shift`: 月次・日次の勤務シフト最適化。
    * `Optamo for Task`: **15分〜30分単位のタスク割当（仕込み、レジ、フライヤー、デリバリー等）まで全自動最適化**。
  * **スキル・相性管理**: スキルレベル（1〜5）、スタッフ間の相性（NGペア/GOODペア）をスコアリングし重み付け調整。
  * **労基法遵守**: 法令条件（36協定、深夜業禁止、連勤制限）を「ハード制約」として組み込み。
* **強み（Pros）**: 数理最適化によるシフト自動生成の完成度・解の質が国内トップクラス。
* **弱み（Cons）**: パラメータチューニングが専門的で導入ハードルが高く、個人店には高価格。

## 3. 既存SaaSが現場で挫折・解約される4大構造要因

```
┌─────────────────────────────────────────────────────────────┐
│              既存SaaSが現場で挫折する 4大要因               │
├──────────────────────────────┬──────────────────────────────┤
│ 1. 料金体系の不合理          │ 2. スタッフ側の利用摩擦      │
│  - 登録人数課金（月1万〜2万） │  - 専用アプリのDL拒否        │
│  - 休眠スタッフも課金対象    │  - ログインPW忘れ・問い合わせ│
├──────────────────────────────┼──────────────────────────────┤
│ 3. 「AI自動作成」の形骸化    │ 4. UIの複雑さと店長交代      │
│  - 暗黙の制約を無視          │  - 初期設定・運用ルールが難解│
│  - 結局手動で一からやり直し  │  - 店長異動でExcelへ先祖返り │
└──────────────────────────────┴──────────────────────────────┘
```

1.  **「登録人数課金」の重荷**: アルバイトの離職率が高く、月数回しか入らない登録スタッフも含めると月額1万〜2万円以上の固定費になり、無料のExcelに戻る。
2.  **アプリインストール拒否・PW忘れ**: 「スマホ容量がない」「バイトのアプリを入れたくない」とスタッフが拒否し、店長にPW再発行の問い合わせが殺到。
3.  **「AI自動作成」の使えなさ**: 金曜夜に新人2人を配置するなど破綻したシフトを出力し、結局手動で組み直す二度手間。
4.  **店長交代による先祖返り**: 初期設定が複雑で、店長異動の引き継ぎ時に使われなくなる。

## 4. 最新の飲食テック（FoodTech）トレンド

1.  **AI売上予測とのシームレス連動**: POSデータ、気象予報、予約台帳を解析し、30分〜1時間単位の来客数・売上高を事前予測。
2.  **変動人件費コントロール（人時売上高・FL比率）**:
    $$\text{人時売上高} = \frac{\text{売上高}}{\text{総労働時間}} \quad (\text{目標: 4,000円〜5,000円})$$
    目標FL比率（55〜60%以内）に収まるよう必要人数を動的逆算。
3.  **スキマバイト（タイミー・シェアフル・メルカリ ハロ）連携**: シフトソルバーで埋まらなかった不足枠（スラック変数）を検知し、ワンクリックで外部ギグワーカー求人を自動出稿。
