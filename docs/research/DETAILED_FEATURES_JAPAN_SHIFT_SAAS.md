# 日本の飲食店シフト管理SaaS・アプリ 【全機能・詳細仕様カタログ】

**作成日**: 2026年8月14日  
**目的**: 日本国内の主要シフト管理システムが備える「全機能」「画面仕様」「アルゴリズム」「制約パラメータ」「現場の細かい仕様」を徹底的に分解・網羅する。

---

## 1. スタッフ向け（従業員・アルバイト）機能 詳細一覧

### 1.1 シフト希望提出・回収機能
*   **希望ステータス入力**:
    *   **◯（出勤可能）**: 時間帯指定（例: 10:00〜15:00）または終日。
    *   **◎（出勤強く希望）**: 最も入りたい時間帯・稼ぎたい日の優先指定。
    *   **✕（出勤不可・休み希望）**: 理由記載（任意/必須設定: テスト、私用、冠婚葬祭等）。
    *   **△（どちらでも可・要相談）**: 条件付き可（例: 13時以降なら可、人手不足なら可）。
    *   **時間帯フリー（いつでも可）**: 店舗の都合に合わせて何時でも入れる指定。
*   **希望入力インターフェース**:
    *   **カレンダータップ型**: 日付を選び、早番/中番/遅番のボタントグル、またはスライダーで時間帯指定。
    *   **ガントバー描画型**: 横軸（時間）に対して指でドラッグして勤務可能帯を引く。
    *   **パターン一括入力**: 「毎週月・水・金の10:00〜14:00」といった固定曜日・固定時間を1ヶ月分ワンタップ流し込み。
    *   **LINEトーク / リッチメニュー**: LINEミニアプリ上でカレンダーを開き、ログイン不要で直接タップ入力。
*   **希望提出リマインド・締切管理**:
    *   **自動リマインド通知**: 締切の3日前、前日、当日にLINEまたはプッシュ通知で自動催促。
    *   **締切後の自動ロック**: 締切日時（例: 毎月20日 23:59）を過ぎると提出フォームが自動クローズ（店長許可で再オープン）。
    *   **提出状況ステータス**: 未読 / 未提出 / 下書き保存 / 提出済み / 差戻し。

---

### 1.2 確定シフト確認・個人管理機能
*   **確定シフト通知・閲覧**:
    *   確定公開時にLINE / プッシュ通知 / メールで一斉配信。
    *   日別・週別・月別カレンダー表示、確定したポジション（ホール/キッチン等）の確認。
*   **私生活カレンダー同期**:
    *   **iOSカレンダー / Googleカレンダー自動同期 (iCal連携)**: 確定シフトが個人のプライベートスケジュールに自動反映。
*   **概算給与・労働時間リアルタイム計算**:
    *   当月の確定シフトから「今月の想定稼働時間」「深夜割増込みの概算給料」を自動計算表示。
    *   「あと〇〇時間で103万円/106万円の壁に到達」といった年間累計バーの表示。
*   **同僚のシフト閲覧（公開範囲設定）**:
    *   店舗設定により「自分のシフトのみ閲覧」「当日の同僚メンバーのみ閲覧」「全スタッフの月間シフト表を閲覧」を切り替え。

---

### 1.3 シフト変更・交代・ヘルプ機能
*   **スタッフ間シフトトレード（交代依頼）**:
    *   「この日入れなくなった」スタッフがアプリ/LINE上で代行者を募集。
    *   代行可能な同僚が「交代引き受け」ボタンを押す ➔ 店長に承認通知が届く ➔ 店長1タップ承認でシフト表が自動書き換え。
*   **欠員・ヘルプ募集へのワンタップ応募**:
    *   店長から配信された「急募: ◯月◯日 18:00-22:00 ホール」通知に対し、空いているスタッフが「入れます」ボタンで即応募。
*   **複数店舗・他店舗ヘルプの管理**:
    *   掛け持ちしている系列店舗（店舗Aと店舗B）のシフトを一元表示し、ダブルブッキングを自動防止。

## 2. 店長・管理者向け「シフト作成・最適化エンジン」機能 詳細仕様

### 2.1 必要人員（デマンド）設定・テンプレート機能
*   **時間帯別・曜日別必要人員マトリクス**:
    *   15分 / 30分 / 1時間刻みで、各時間帯に必要な人数を定義（例: 12:00-13:00は5名、15:00-17:00は1名）。
    *   **曜日パターン**: 平日（月〜木）、金曜、土日祝、祝前日、特定イベント日（繁忙期）ごとのテンプレート保存。
*   **ポジション・職能別デマンド**:
    *   「11:30〜14:00: ホール2名、キッチン温場1名、キッチン冷場1名、洗い場1名」といったポジションごとの個別人数指定。
    *   **役職・責任者常駐制約**: 「全営業時間を通じて、店長代行（レジ締め・食品衛生責任者）が常時最低1名存在すること」。

---

### 2.2 最適化ソルバー・アルゴリズム機能（数理モデル・制約パラメータ）
*   **Hard制約（100%厳格遵守・違反を絶対に許さない制約）**:
    1.  **年少者深夜禁止（労基法第60条）**: 満18歳未満（高校生）の22:00〜05:00勤務割当変数は例外なくゼロ。
    2.  **不可シフト（Unavailable）の完全除外**: スタッフが✕を出した日・時間帯には絶対に割り当てない。
    3.  **連続勤務日数上限**: スタッフごとの上限日数（例: 最大5連勤）を超えて連続出勤させない。
    4.  **1日1勤務原則（ダブルブッキング防止）**: 同一スタッフが同日に重複するシフト枠に入らない。
    5.  **週最大労働時間上限**: スタッフごとの契約時間（例: 週20時間 / 40時間）を超過させない。
    6.  **勤務間インターバル**: 前日退勤から翌日出勤までに指定時間（例: 11時間以上）を空ける。
*   **Soft制約（ペナルティ付き目的関数・可能な限り最適化する条件）**:
    1.  **希望シフト（Want/◎）の最大充足**: ◎を出した枠への割当にプラススコア（または未割当にペナルティ）。
    2.  **人件費最小化（Labor Cost）**: 時給の高いスタッフの無駄な配置を避け、必要人数ピッタリに収める。
    3.  **出勤日数の公平性（Fairness）**: 同一属性（フリーター同士など）の間で、月間出勤日数・稼働時間の格差を最小化。
    4.  **目標労働時間の達成**: スタッフごとの「月間希望稼働時間（例: 月80時間）」に近づける。
    5.  **スキル・熟練度バランス**: シフトごとのスタッフ平均スキルスコアを均等化（新人ばかりの時間帯を作らない）。
    6.  **相性制約（NGペア / GOODペア）**:
        *   **NGペア**: 仲の悪いスタッフ同士、または新人×新人のペアを同一時間帯に配置しない（重いペナルティ）。
        *   **GOODペア**: ベテランと新人をセットで配置する（推奨ボーナス）。
*   **スラック緩和変数（Graceful Degradation / 欠員可視化）**:
    *   必要人数に対して希望スタッフが全員NGで人手不足の場合、ソルバーがエラー落ち（Infeasible）せず、**「不足枠（Under-staffed）」を変数として解を出力**し、画面上で赤色ハイライト表示する。

---

### 2.3 管理画面UI・シフト編集・マトリクス操作
*   **マトリクス表示・ビュー切り替え**:
    *   **スタッフ軸（縦: スタッフ名 / 横: 日付）**: 月間全体の出勤パターン・連勤・休みが一目でわかる。
    *   **時間軸・ガントチャート（縦: 時間帯 10:00〜24:00 / 横: 日付またはスタッフ）**: 時間帯別の過不足が一目でわかる。
    *   **ポジション別表示**: ホール / キッチン / 洗い場ごとの別シート表示。
*   **直感的なドラッグ＆ドロップ編集**:
    *   マトリクス上のシフトバーをマウスでドラッグして時間延長・短縮・別スタッフへ移動。
    *   手動変更時に、労基法違反や重複があると**リアルタイムで警告トースト/赤枠表示**。
*   **過不足メーター（Need vs Assigned）**:
    *   シフト表の最下行・最上行に「必要人数」「割当人数」「過不足差分（±0, -1, +1）」をカラーメーターで常時表示。
    *   人手不足（赤）、過剰（青）、適正（緑）。
*   **下書き・バージョン管理・差分比較**:
    *   「下書き（Draft）」状態で何パターンもシミュレーション可能。
    *   「最適化実行前」「最適化案A」「手動修正後」をワンクリックで切り替え・差分比較。

## 3. 労務管理・労働基準法・コンプライアンス自動判定機能

*   **労働基準法 リアルタイムアラート**:
    *   **週40時間超過アラート**: 週初め〜週末の累計実働時間が40時間を超える場合に警告。
    *   **1日8時間超過・時間外労働判定**: 8時間超の勤務に対して自動で残業割増（25%UP）計算。
    *   **深夜割増（22:00〜05:00）自動判定**: 22時以降にかかる勤務時間を自動分離し、深夜手当（25%UP）を適用。
    *   **法定休憩時間 自動挿入 / 不足チェック**:
        *   実働6時間超 ➔ 最低45分の休憩が設定されているか検証（自動挿入オプション）。
        *   実働8時間超 ➔ 最低60分の休憩が設定されているか検証。
    *   **連続勤務アラート**: 6連勤以上、または法定休日（週1日/4週4日）未取得を検知。
*   **「年収の壁」・社会保険・扶養控除トラッキング**:
    *   **103万円の壁（所得税・親の扶養）**: 年間累計給与を月別シミュレーションし、秋口（10月〜12月）に枠オーバーしそうなスタッフを一覧警告。
    *   **106万円の壁（社会保険加入義務）**: 週20時間以上かつ月額8.8万円以上の勤務パターンを検知。
    *   **130万円の壁（配偶者扶養）**: 年間見込み給与が130万円を超えるペースの場合に警告。

## 4. 人件費・予実管理・売上連動（FLコスト最適化）機能

*   **概算人件費 リアルタイムシミュレーション**:
    *   スタッフごとの個別時給（基本給、役職手当、高校生時給等）× 勤務時間 ＋ 深夜割増 ＋ 残業割増 ＋ 交通費を一瞬で合算。
    *   シフトを1コマ動かすたびに「当月人件費合計」「日別人件費」がリアルタイムに再計算。
*   **人時生産性・人時売上高の自動算出**:
    *   $$\text{人時売上高} = \frac{\text{売上予測}}{\text{当日の総労働時間（人時・Man-Hours）}}$$
    *   目標人時売上高（例: 5,000円/h）を下回る時間帯（過剰人員）を青色で警告。
*   **FL比率（Food & Labor Cost）コントロール**:
    *   売上目標に対する人件費率（目標: 28〜30%）のリアルタイム達成率メーター。
*   **POSレジ・売上予測データ連携**:
    *   過去のPOS売上データ、曜日傾向、予約台帳（人数・コース）を取り込み、30分ごとの「推奨必要人員数」を自動算出。

## 5. 店舗間ヘルプ・欠員補充・外部ギグワーク連携機能

*   **店舗間ヘルプ募集・マッチング（チェーン向け）**:
    *   自店舗で埋まらなかった欠員シフトを、近隣系列店舗（同エリア）のスタッフへ「ヘルプ募集」として一斉配信。
    *   他店スタッフが応募した場合、自店シフト表に「（ヘルプ）〇〇店 佐藤」と自動反映。
*   **店舗間人件費振替（労務・会計機能）**:
    *   ヘルプ勤務したスタッフの給与・労働時間を「応援先店舗」の人件費勘定に自動振替（KING OF TIME / ジョブカン連動）。
*   **スキマバイト（外部ギグワーカー）ワンクリック求人出稿**:
    *   社内スタッフで埋まらなかったシフト枠（不足枠）を検知。
    *   「タイミー（Timee）」「シェアフル」「メルカリ ハロ」などのスポットワーク求人票へボタン1つで自動変換・API出稿。
    *   マッチングした外部ワーカーの名前がシフト表の欠員枠に自動で埋まる。

## 6. 日常運用・当日オペレーション・突発対応機能

*   **当日出勤ボード（点呼・リアルタイム状況）**:
    *   iPadや店舗PCで、本日出勤予定のスタッフ一覧、現在勤務中、休憩中、退勤済みをリアルタイム表示。
    *   遅刻・未出勤スタッフを赤色表示し、店長にLINE/電話プッシュ通知。
*   **タイムカード・打刻連動**:
    *   店舗タブレット（顔認証・ICカード・QRコード・PINコード）またはスタッフスマホ（GPS位置情報打刻 / LINE打刻）。
    *   「シフト予定時間」と「実打刻時間」の乖離（早出・残業・遅刻・中抜け）を自動ハイライト。
*   **日次タスク割当・ポジション表作成**:
    *   シフト確定後、その日の15分/30分ごとの「ポジション割当表（誰が何時にレジ、焼き場、仕込み、洗い場に入るか）」を自動印刷・画面表示。

## 7. シフト共有・出力・外部連携機能

*   **共有・通知機能**:
    *   **LINE一括テキスト生成**: LINEグループ送信用に整形された「日付・名前・時間帯」テキストのワンクリックコピー。
    *   **PDF / 画像エクスポート**: バックヤードや休憩室に貼り出すためのA4/A3横シフト表PDF出力。
    *   **Web閲覧用URL発行**: スタッフがログイン不要で最新シフトを確認できるセキュアな閲覧専用URL。
*   **データ出力・給与ソフト連携**:
    *   **CSV / Excelエクスポート**: 給与奉行、弥生給与、freee人事労務、マネーフォワード給与、PCA給与等への完全準拠フォーマット出力。
    *   **API連携**: 勤怠管理・給与計算・POSレジ・予約台帳との双方向API通信。
