# ADR-003: フロントエンド技術・UIライブラリの選定（Next.js + Schedule-X の採用）

* **ステータス**: 承認済み (Accepted)
* **日付**: 2026-08-14
* **決定者**: コウヘイ & Antigravity

---

## 1. 背景と課題

飲食店向けシフト作成AIアプリの試作品（MVP）において、**「クライアントがスマホから直感的に希望シフトを入力でき、PC/タブレット上でAIが算出した最適シフト表（ガントチャート）を一覧・調整できる洗練されたWeb UI」** を構築する。

### 前提要件
* **ライセンス**: MIT License（商用可・完全無料）。
* **レスポンシブ**: スマホ（タップ・縦スクロール最適化）とPC（ワイド画面ガントチャート）のマルチデバイス対応。
* **0円ホスティング親和性**: Vercel無料枠でエッジ配信され、瞬時にロードされること。

---

## 2. 調査候補一覧

| 候補 | 技術構成 | スケジュールUI | 主な特徴 |
| :--- | :--- | :--- | :--- |
| **候補1 (採用)** | **Next.js (App Router, TS)** | **Schedule-X (MIT)** | Vercel最適化、SSR/Static配信、スマホ/PC両対応のOSSスケジューラー |
| **候補2** | Vite + React (SPA) | Schedule-X (MIT) | 軽快なSPAだがVercel等の統合度でNext.jsに一歩譲る |
| **候補3** | FastAPI + Jinja2/HTML/JS | 完全自作 (Vanilla JS) | バックエンド単一完結だが、Renderスリープ時に画面ごと待たされ工数大 |

| 評価軸 | 候補1: Next.js + Schedule-X | 候補2: Vite + React | 候補3: FastAPI + Vanilla JS |
| :--- | :--- | :--- | :--- |
| **ライセンス** | MIT | MIT | 完全自作 |
| **スマホ操作性 (希望入力)** | **★★★★★ 快適** (タップ最適化UI) | **★★★★☆ 良好** | **★★★☆☆ 普通** |
| **PC操作性 (ガントチャート)** | **★★★★★ 抜群** (Schedule-X) | **★★★★★ 抜群** | **★★☆☆☆ 低い** (自作工数大) |
| **画面初期表示速度 (スマホ)** | **★★★★★ 最速 (Vercel Edge)** | **★★★★☆ 高速** | **★★☆☆☆ 遅い (Render待機)** |

## 4. 決定理由と経緯

**【決定】: 候補1（Next.js + Schedule-X + レスポンシブCSS）を採用する。**

### 採用に至った決定打
1. **Schedule-X (MIT) による開発工数短縮と完成度**:
   * シフト表・ガントチャートは自作するとドラッグ操作や時間グリッド計算に数週間の工数がかかるが、実績のある軽量OSSを活用することで数日で商用レベルのUIが構築できる。
2. **スマホファーストの希望入力画面**:
   * アルバイトスタッフやオーナーが外出先で触る「シフト希望入力画面」は、スマホ専用のタップしやすいUIとして設計可能。
3. **Vercelエッジ配信による信頼性**:
   * APIサーバー（Render）がスリープ中でもフロントエンド画面自体は0.1秒で表示され、ユーザーにストレスを与えない。
