# ADR-003 補遺: Schedule-X MIT版の制限と対応方針

* **ステータス**: 更新済み (Amended)
* **日付**: 2026-08-14
* **関連**: [ADR-003](003-frontend-ui-selection.md)

---

## 調査で判明した制限事項

Schedule-X のMIT（無料）版には以下の機能が**含まれていない**：

| 機能 | MIT (無料) | Premium (有料) |
| :--- | :--- | :--- |
| 基本ビュー (Day/Week/Month) | ✅ | ✅ |
| イベント色分け・カスタム描画 | ✅ | ✅ |
| Next.js App Router 対応 | ✅ | ✅ |
| モバイルレスポンシブ | ✅ | ✅ |
| **リソースビュー (縦軸スタッフ×横軸時間)** | **✕** | ✅ |
| **ドラッグ＆ドロップ** | **✕** | ✅ |

## 対応方針（0円維持のための設計変更）

### 採用する構成
1. **Schedule-X MIT版**: 週間カレンダービュー（シフトをイベントとして色分け表示）に使用。
2. **カスタム HTML テーブル / CSS Grid（自作）**: 管理者向けの「スタッフ×シフト枠マトリクス表」を自作。
   - 縦軸: スタッフ名 / 横軸: 日付×シフト枠
   - 色分け: ロール別（ホール=青、キッチン=緑）
   - 不足箇所: 赤ハイライト
   - ドラッグ＆ドロップは**MVP不要**（最適化エンジンが自動配置するため手動調整の必要性が低い）

### 理由
* ドラッグ＆ドロップは「AIが最適解を出す」アプリでは優先度が低い（人間が手動で動かす設計ではない）。
* リソースビューは単純なHTMLテーブル＋CSSで十分に実装可能であり、有料ライセンスを購入する必要がない。
* 将来的にドラッグ調整が必要になった場合は、Premiumライセンス取得またはOSS代替（React DnD等）を検討する。
