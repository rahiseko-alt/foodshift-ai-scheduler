## 1. 画面構成と主要機能

フロントエンドは大きく分けて2つの主要ビュー（または画面）で構成される。

### 1.1. スタッフ向け画面（スマホ最適化ビュー）: `/submit`
* **対象ユーザー**: アルバイトスタッフ、外出先の店長
* **主要機能**:
  * スタッフ選択（自分を選択）
  * 対象週のカレンダー表示
  * 日別・時間帯別の「出勤可能（◯）」「NG（✕）」「希望（◎）」のタップ切り替え
  * 希望コメント（「テスト期間のため早め希望」等）の入力
  * 送信ボタン（ローカル/APIへ保存）

### 1.2. 管理者向け画面（PC/タブレット最適化ビュー）: `/admin`
* **対象ユーザー**: 店舗オーナー、店長
* **主要機能**:
  1. **条件設定パネル**:
     * 各時間帯（早番・中番・遅番等）の必要人数（ホール/キッチン）の設定
     * 売上予測データのインポート（※後フェーズ連携・単独手入力も可）
  2. **スタッフ一覧 & 制約管理**:
     * スタッフの時給、年齢（18歳未満フラグ）、スキル（キッチンリーダー等）、週労働時間上限の確認
  3. **⚡ 最適化実行ボタン**:
     * バックエンドAPI（OR-Tools）を呼び出し、最適シフトを自動生成
  4. **シフトガントチャート / カレンダー（Schedule-X）**:
     * 横軸：日付・時間 / 縦軸：スタッフ別 or シフト枠別のビジュアル表示
     * 人員不足箇所のハイライト表示（赤色アラート）
     * 人件費の自動集計・総勤務時間の表示

## 2. APIクライアント連携仕様

* **APIエンドポイント**: `POST /api/v1/optimize-schedule`
* **リクエスト**: [SPEC-001](../specs/001-shift-scheduler-engine-spec.md) に準拠したJSON
* **ローディング/エラーハンドリング**:
  * サーバー起動中アニメーション（Renderのコールドスタート対応）
  * Infeasible（解なし）時の緩和解＆不足アラートの可視化
